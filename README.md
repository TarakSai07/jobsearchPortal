# Job Search Portal Using Bootstrap

A simple and responsive **Job Search Portal** built using **HTML5 and Bootstrap 5**. This project provides a basic interface where users can search for jobs and view the latest job listings.

## 🚀 Features

* Responsive Job Search Portal
* Navigation bar with Home, Jobs, Companies, About Us, and Contact sections
* Job search form with:

  * Keywords
  * Location
  * Company
* Latest Job Listings section
* Job cards with company, location, and description
* "Apply Now" buttons
* Responsive design for different screen sizes
* Bootstrap components and utility classes

## 🛠️ Technologies Used

* **HTML5**
* **Bootstrap 5.3.3**

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Explore the Job Search Portal.
